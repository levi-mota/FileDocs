# Guia de uso

## Pelo clique direito

Clique com o botão direito num PDF, imagem ou documento do Office → **Mostrar mais opções** → **FileDocs**.

| Arquivo | Opções |
|---|---|
| PDF | Abrir no FileDocs, Comprimir, OCR, Converter para PNG |
| Imagem | Abrir no FileDocs, Converter para PDF / JPG / PNG, OCR → PDF pesquisável |
| Word/Excel/PPT | Abrir no FileDocs, Converter para PDF |

Uma janelinha mostra o progresso e, no fim, o botão **Abrir local**.
Com vários arquivos selecionados em **Abrir no FileDocs**, todos entram na mesma janela.

## Pela janela

1. Abra o FileDocs (atalho na Área de Trabalho ou no Menu Iniciar).
2. Escolha a ferramenta na barra da esquerda.
3. Arraste os arquivos para a área central, ou clique nela para escolher.
4. Ajuste a ordem com ▲▼ ou arrastando (vale para **Juntar**).
5. Preencha o campo, se a ferramenta pedir, e clique em **Executar**.

### Campos

- **Extrair / Remover páginas:** `1-3,5,8-` (de 1 a 3, a 5 e da 8 até o fim).
- **Girar:** 90, 180 ou 270.
- **Comprimir:** qualidade de 1 a 100 (padrão 60; valores menores geram arquivos menores).
- **OCR:** idiomas, padrão `por+eng`.
- **PDF → Imagens / Converter imagem:** formato de saída (`png`, `jpg`...).

## Onde ficam os resultados

Ao lado do arquivo original, com sufixo: `contrato_comprimido.pdf`, `contrato_ocr.pdf`, `contrato_unido.pdf`.
Divisões e PDF → imagens criam uma pasta (`contrato_paginas`, `contrato_imagens`).
O original nunca é alterado nem sobrescrito.

## Desinstalar

Configurações do Windows → Aplicativos → FileDocs → Desinstalar. O menu de contexto sai junto.
